# PRD: Orbit — 취향 기반 소셜 매칭 앱

## 1. 제품 개요
취향(음악, 영화, 운동, 음식, 여행 등)을 기반으로 비슷한 관심사를 가진 사람들을 매칭해주는 건전한 소셜 채팅 앱.

## 2. 핵심 가치
- **취향 매칭**: 단순 랜덤이 아닌, 관심사 유사도 기반 매칭
- **건전성**: 신고/차단/필터링으로 안전한 환경
- **커뮤니티**: 1:1 채팅뿐 아니라 동호회(모임) 기능

## 3. 타겟 사용자
- 20~30대, 새로운 취미 친구를 찾고 싶은 사람
- 동네/온라인 동호회에 참여하고 싶은 사람

## 4. 핵심 기능

### 4.1 회원가입 & 프로필
- 이메일/소셜 로그인
- 취향 카테고리 선택 (최소 3개)
  - 음악 (장르: 팝, 힙합, 클래식, 인디 등)
  - 영화 (장르: 액션, 로맨스, 다큐, 호러 등)
  - 운동 (종류: 러닝, 헬스, 등산, 축구 등)
  - 음식 (종류: 한식, 일식, 카페, 비건 등)
  - 여행 (스타일: 배낭여행, 호캉스, 캠핑 등)
  - 게임, 독서, 반려동물 등 확장 가능
- 자기소개, 프로필 사진

### 4.2 취향 매칭 1:1 채팅
- 취향 유사도 점수(코사인 유사도) 기반 매칭
- 매칭 요청 → 상대방 수락 → 채팅방 생성
- 실시간 채팅 (텍스트, 이미지)

### 4.3 동호회 (커뮤니티)
- 카테고리별 동호회 생성
- 동호회 검색 및 가입
- 그룹 채팅
- 모임 공지/일정 관리
- 최대 인원 설정 가능

### 4.4 건전성 시스템
- 욕설/비속어 자동 필터링
- 신고 기능 (사유 선택)
- 차단 기능
- 신고 누적 시 자동 제재 (경고 → 일시정지 → 영구정지)

### 4.5 알림
- 매칭 요청 알림
- 채팅 메시지 알림
- 동호회 공지 알림

### 4.6 비로그인 접근
- 로그인/회원가입 없이 홈 화면(피드, 동호회 목록, 인기 취향 등) 열람 가능
- 비로그인 상태에서도 1:1 채팅 및 그룹 채팅 참여 가능
  - 임시 닉네임 자동 부여 (예: "궤도여행자#3847")
  - 앱 종료 또는 일정 시간 경과 시 대화 기록·프로필 자동 소멸
  - 채팅방 내 "게스트" 뱃지로 비회원 표시
  - 회원가입 유도 배너: 대화 중 자연스럽게 "가입하면 대화 기록이 보존됩니다" 안내
- 비로그인 사용자 제한: 프로필 커스터마이즈, 매칭 요청, 동호회 생성 불가

### 4.7 취향 시각화 & 인터랙션
- 취향 카테고리를 실제 사진 이미지 카드로 시각화 (예: 러닝 → 공원에서 달리는 사진, 한식 → 한정식 사진 등)
- 취향 유사도를 레이더 차트(오각형 그래프)로 표현
- 취향 태그 선택 시 애니메이션 피드백 (탭 → 확대/색상 변화)
- 홈 화면에 "오늘의 취향 매칭" 카드 슬라이더 (이미지 + 유사도 %)
- 프로필 화면에서 상대방과 나의 취향 겹침을 벤다이어그램으로 시각화

## 5. 비기능 요구사항
- 실시간 메시지 전송 지연 < 500ms
- 동시 접속 1,000명 처리
- 개인정보 암호화 저장
